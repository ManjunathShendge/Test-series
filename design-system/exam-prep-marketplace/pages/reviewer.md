# Reviewer page override

Inherits [MASTER](../MASTER.md). Compact navigation, readable question pane, optional evidence pane. On narrow screens evidence becomes accessible tabs; no simultaneous unreadable columns. Show exact version ID/submission and approval state.

Display English/Hindi, correct key/worked solution, duplicate evidence with provenance, AI suggestion label, topic-count warning and manual checklist. Separate rule blocks from warnings. Approve, minor edit, request change and reject have clear labels; last two require reason. Unsaved verdict state visible; keyboard actions never submit accidentally.

AI suggestion has Accept/Edit/Ignore where applicable; no button implies automatic verified correctness. Changed approved content creates a version with review-required badge. Queue shows flag count, assignee and SLA deadline; sort state and filters announced. Mask KYC and unnecessary student information in this workflow.
