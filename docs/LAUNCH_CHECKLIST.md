# Launch gates

Unchecked means unverified; documentation completion does not satisfy implementation gates.

- [ ] Founder resolves relevant O01-O12 in DECISIONS, including exact templates and price policies.
- [ ] Content license/agreement, student terms, refund/privacy policies, named grievance contact and retention reviewed by legal/CA.
- [ ] Store product type/correlation/restore spike accepted; organization developer accounts, required enrollment/D-U-N-S, agreements, banking and tax setup complete.
- [ ] Twenty or more examiners onboarded, samples/KYC/agreement approved; chosen 20/50 tests per exam reviewed. Use actual question counts for reviewer hours.
- [ ] Last-five-years PYQ coverage register records available years/shifts and missing papers; no claim of complete corpus without evidence.
- [ ] Trigram ~200-pair calibration signed off; Hindi review and reviewer capacity/48h SLA covered.
- [ ] Complete student/examiner/reviewer/finance E2E tested; keys never leak to active students.
- [ ] Payments in store sandboxes and Razorpay test mode pass recovery/refund/replay/restore; live credentials separated and audited.
- [ ] Finance confirms tax/share/net definitions, invoice issuer and payout reconciliation with hand-checked fixtures.
- [ ] Security/ownership/privacy/deletion/accessibility tests pass; capture behavior checked on actual iOS/Android.
- [ ] Clean-clone setup, CI, migrations, monitoring, backup/restore drill and incident owners verified.
- [ ] Performance/app-size evidence recorded; founder live concurrency target/load test completed before first live feature release.
- [ ] Closed beta: 500 students for two weeks; bugs/failed payments/answer-loss reports triaged and resolved.
- [ ] Google Play listing, Data Safety, rating/audience/ads disclosures, privacy/deletion URLs; internal -> closed -> staged release prepared.
- [ ] Apple listing, App Privacy/age rating, support/privacy URLs and in-app deletion; TestFlight -> review -> release prepared.
- [ ] Web domain/TLS/CDN, sitemap/canonical metadata/Search Console and shared login/access verified.
- [ ] Phase 2 features disabled; production rollout and rollback owner approval recorded.

Store acceptance, legal compliance and live performance are external gates, not promised by these documents. Record evidence links/date/owner in PROJECT_STATUS.
