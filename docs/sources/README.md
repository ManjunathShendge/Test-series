# Source inputs

Some source documents are deliberately **not** published to this repository. They are
client-confidential inputs held locally by the project owner and listed in `.gitignore`:

| File | What it is | How to get it |
|---|---|---|
| `PRD__Exam_Prep_Marketplace.pdf` | Original product requirements, 19 pages, dated 2 November 2026 | Request from the project owner |
| `requirement.text` | Requirements draft plus the later authentication and store-billing amendments | Request from the project owner |
| `docs/PRD.md` | Page-marked text transcription of the PDF above; same confidential content | Request from the project owner |

Links to `PRD.md` from [REQUIREMENTS](../REQUIREMENTS.md), [DECISIONS](../DECISIONS.md) and
[SOURCES](../SOURCES.md) therefore resolve only in a working copy that has the file. This is
expected; it is not a broken-link defect to fix by deleting the references.

Everything these sources decide is reflected in the published documentation:
requirement traceability in [REQUIREMENTS](../REQUIREMENTS.md), the authoritative
reconciliation in [DECISIONS](../DECISIONS.md), and provenance in [SOURCES](../SOURCES.md).
Work from those; treat the raw sources as evidence of record rather than day-to-day references.

The published note in this folder is owner-supplied and preserved verbatim with a provenance
header. Keep that convention for any future source added here, and check whether a new source
belongs in `.gitignore` before committing it.
